## Race and ethnicity are never scored
`acs_tract` / `acs_bg` carry B03002 race/ethnicity counts for aggregated equity context only (the Nonprofit and Policy seats show them for an area). They must never feed any parcel score, rank, factor, red flag, filter default, eligibility rule or planning badge. Any code that reads `nh_white`, `nh_black`, `nh_asian`, `nh_other`, `nh_two_or_more`, `hispanic` or `pop_race_universe` for a parcel-level computation is a bug.

## Personal data removed at ingest
- Assessments: owner mailing-address fields (read only locally to recognise public-agency and housing-nonprofit offices for `parcel_owner_class`; never uploaded), legal descriptions, deed book/page, prior-sale history. The county does not publish owner names.
- Map layers: GIS editor user names (`created_user`, `last_edited_user`) are never loaded.
- Permits and condemned properties: owner, contractor, and description fields are never read. The pending-review spreadsheet's addresses and work descriptions are read only to skip them; only permit number, type, structure type, and dates are used.
- Zoning decisions: Appearances sections, party lines (applicant, owner, attorney, objector), findings, and signatures are dropped; remaining free text is name-scrubbed.
- Sales: the county file has no buyer/seller names; deed book/page is not kept.
